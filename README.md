# Mews House

Heritage townhouse and mews estate landing. Deep teal, cream, Art Deco condensed type. Light-custom: logo, colours, fonts, copy, and section on/off. Demo copy is generic.

Live demo: https://mews.little.website/

## Features

- Heritage townhouse and mews estate landing
- Light-custom: logo, colours, fonts, and copy
- Section on/off for hero, house, rooms, grounds, visit, and contact
- Deep teal, cream, and peach Art Deco palette
- Condensed display type (Oswald)
- Generic demo copy
- Fully responsive Astro SSG

## Design

Typography:
- display: Oswald
- ui: Space Grotesk

Colors:
- Deep teal: #003A4E
- Peach: #FFBC7D
- Cream: #FBDDB9
- sand: #F1E2CE

## Customization

Light-custom: logo, colours, fonts, copy, and section on/off.

Edit src/data/site.ts and CSS variables in src/styles.

Page sections:
- Hero
- House
- Rooms
- Grounds
- Visit
- Contact

Use cases:
- Heritage estates
- Townhouse listings
- Boutique venues
- Historic properties

## Stack

Astro 5 SSG, CSS variables, TypeScript, Vite.
Fonts: Oswald, Space Grotesk
